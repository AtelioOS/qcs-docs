Connecting the QCS Operating System to Microsoft 365

Setup guide for your Microsoft administrator · enables automated email (invoices, quotes, POs, service reminders) and calendar sync for Quality Coffee Systems' new operating system.

⏱ About 10 minutes · requires a Global Administrator or Application Administrator role
What this creates and why it's safe: a single "app registration" in your own Microsoft tenant that lets the QCS OS send email from one shared mailbox and manage service-calendar events. You control it entirely — you can see everything it's allowed to do, restrict it to specific mailboxes (step 6), and revoke it at any time by deleting it. No passwords are shared and nothing touches personal inboxes.

1 Create the app registration

  1. Go to entra.microsoft.com and sign in with your admin account.
  2. In the left menu: Identity → Applications → App registrations.
  3. Click ＋ New registration (top of the page).
  4. Name: QCS OS (Atelio) · Supported account types: leave the default "Accounts in this organizational directory only (Single tenant)" · leave Redirect URI empty.
  5. Click Register.
Illustration of the screen — the highlighted parts are where to click:

2 Copy the two IDs

After registering you land on the app's Overview page. Copy these two values (there's a copy icon next to each) — they go back to Viviana:

  • Application (client) ID
  • Directory (tenant) ID

3 Add the two permissions

  1. In the app's left menu click API permissions → ＋ Add a permission.
  2. Choose Microsoft Graph → Application permissions (⚠ not "Delegated").
  3. Search for and tick Mail.Send, click Add permissions.
  4. Repeat: add Calendars.ReadWrite.

"…as any user / all mailboxes" sounds broad — step 6 locks it down to just the mailboxes you choose.

4 Grant admin consent

Still on API permissions: click ✓ Grant admin consent for [your organization] and confirm. The Status column for both permissions turns to a green check "Granted". This is the approval step — without it, nothing works.

5 Create the client secret

  1. App's left menu → Certificates & secrets → ＋ New client secret.
  2. Description: QCS OS · Expires: 24 months → Add.
  3. Copy the Value column immediately — it is shown only once. (Not "Secret ID" — the Value.)
⚠ The secret is the sensitive piece. Don't email it in plain text — hand it to Viviana over the phone, a password manager share, or a one-time-secret link. The two IDs from step 2 are fine over email.

6 Create the sending mailbox & lock the app to it

6a — shared mailbox (free, no license): in admin.exchange.microsoft.com → Recipients → Mailboxes → ＋ Add a shared mailbox → name it service@qualitycoffeesystems.ca (or your preference — tell Viviana which).

6b — restrict the app to that mailbox (recommended): this makes the "any user" permission from step 3 physically limited to the mailboxes you choose. In Exchange Online PowerShell:

Connect-ExchangeOnline

# One mail-enabled security group holding the mailboxes the OS may use
New-DistributionGroup -Name "QCS OS Mailboxes" -Type Security
Add-DistributionGroupMember -Identity "QCS OS Mailboxes" -Member service@qualitycoffeesystems.ca

# Restrict the app (use the Application ID from step 2)
New-ApplicationAccessPolicy -AppId <APPLICATION-ID> `
  -PolicyScopeGroupId "QCS OS Mailboxes" `
  -AccessRight RestrictAccess `
  -Description "QCS OS may only use these mailboxes"

# Verify: should say Granted for service@, Denied for anyone else
Test-ApplicationAccessPolicy -AppId <APPLICATION-ID> -Identity service@qualitycoffeesystems.ca

If you'd like the OS to also write service appointments to technicians' own calendars later, add those mailboxes to the same group — nothing else changes.

7 Send it back

Checklist — five things to Viviana:

  1. Directory (tenant) ID — email is fine
  2. Application (client) ID — email is fine
  3. Client secret value — phone / password manager / one-time link only
  4. Sending mailbox address you created (e.g. service@…)
  5. Confirmation that admin consent shows "Granted" (step 4)
That's it. Once received, the QCS OS starts sending invoices, quotes, purchase orders and maintenance reminders from your own address the same day, and service calendars sync automatically. You can revoke access at any time: delete the client secret (instant cut-off) or the whole app registration.
